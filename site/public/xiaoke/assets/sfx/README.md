# 小克的打字声 · Xiao Ke's bubble voice

Eight short paper taps and one softer cadence tap, synthesized for Xiao Ke from
damped wooden resonances and filtered noise. No recordings or third-party
samples were used. Each WAV is mono 16-bit PCM at 48 kHz.

Use one of voice-01.wav through voice-08.wav for a typed glyph. Use voice-end.wav
for ，。？！. Spaces and other punctuation are silent. Actor.voiceEvents()
returns the matching event times in seconds.

The WAV files are dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
